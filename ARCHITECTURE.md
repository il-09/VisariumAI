# Архитектура VisariumAI (MVP)

```text
Браузер (HTML/CSS/JS из прототипа)
          │ same-origin HTTP
          ▼
Go net/http API
 ├── POST /api/chat ──► сценарная маршрутизация + лексический поиск
 ├── GET  /api/knowledge ──► локальные выдержки и источники
 ├── GET  /api/templates ──► перечень модулей
 ├── POST /api/check ──► извлечение текста DOCX/TXT + базовые проверки
 └── GET  /api/health
          │
          ▼
knowledge/knowledge.json
  выдержки из предоставленной Инструкции, Матрицы,
  Методических рекомендаций и модулей документов
```

## Как формируется ответ

1. Сервер принимает вопрос и ограничивает размер запроса.
2. Лексический поиск сопоставляет слова запроса с названием, текстом, ключевыми словами и ссылками фрагментов.
3. Для часто используемых сценариев (модули, визирование, ИС, передача дел, рабочая группа, подписание) применяются ответы, основанные на соответствующих положениях источников.
4. В ответ добавляются названия источников. Если подтверждений мало, помощник сообщает об этом и запрашивает уточнения вместо выдумывания требований.

## Основные сценарии демонстрации

1. «Как проверить актуальность модуля?» — реестр, версия, владелец и начало применения.
2. «Кто визирует приказ о вводе информационной системы в эксплуатацию?» — строка 3 Матрицы и общий маршрут.
3. «Какие сведения нужны для распоряжения о создании рабочей группы?» — цель, состав, срок, результат и контроль.
4. Загрузка DOCX на странице проверки — базовые автоматические признаки, с предупреждением, что это не полноценная правовая экспертиза.
5. Вопрос вне базы — демонстрация безопасного отказа от догадки.

## Границы MVP и безопасность

В MVP нет внешней языковой модели, аккаунтов, корпоративной SSO, полноценной ролевой авторизации и семантической векторной базы. Материалы хранятся локально; пользовательские вопросы не пересылаются внешнему API. Проверка документов предварительная. Для корпоративного внедрения требуется дополнительная оценка ИБ, разграничение доступа, управление редакциями и официальное подтверждение источников.
